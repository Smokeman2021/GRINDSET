# GRINDSET — индекс базы знаний (партии 001–022)

Обновлено 16.11. Рабочий язык — RU, выпуск — UA. Импорт материалов в приложение — отдельное ТЗ; этот файл только описывает, что есть и в каком статусе.

## Статусы

| Метка | Значение | Можно в приложение? |
|---|---|---|
| **готово** | Авторская карточка, `status: ready`, есть ID | Да, после вычитки UA |
| **методика** | Авторский конспект, чек-лист или шаблон. Пригоден как основа будущих методичек | Да, в переработанном виде |
| **учебный расчёт** | Цифры придуманы или выведены для упражнения. Не наблюдение рынка | Да, с пометкой «учебные данные» |
| **опубликованный бенчмарк** | Средний показатель из опубликованной выборки (например CPL LocaliQ) | Как ориентир с источником, датой и рынком выборки |
| **производная оценка** | Наш расчёт поверх бенчмарка (например CPL × число заявок). Не наблюдение | Только с пометкой «расчёт» |
| **самоотчёт** | Цифры автора публикации на форуме. Первичных отчётов нет | Только как пример «как читать чужой отчёт», не как норма |
| **внутреннее** | Реестры источников, каталоги статей, ссылки | Нет. Остаётся у редактора, исключено из клиентской сборки |
| **черновик** | Требует сверки или доработки | Нет |

Правило: самоотчёты, учебные расчёты и подтверждённые данные не смешиваются в одной таблице без метки.
