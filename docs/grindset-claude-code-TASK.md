# ЧАСТИНА 1 — ЯК ВОНО МАЄ БУТИ

GRINDSET — це **не Duolingo-ланцюг кружечків**. Це **один Київ, яким гравець піднімається** від околиці до центру, навчаючись медіабаїнгу.

1. **Курс = подорож містом.** Кожен урок/модуль — **локація Києва** (кімната на околиці, забігайлівка, метро, кафе, коворкінг, офіс, дах, ресторан, набережна, Печерськ). Проходження курсу = **маршрут цим містом**. Не «тисну наступний кружечок» — **приїжджаю в наступне місце**.
2. **Перехід між уроками = ПЕРЕЇЗД.** Не телепорт на вузол, а **анімація дороги**: транспорт за актом (пішки/метро/маршрутка → дешеве авто → оптимальне → люкс) їде по екрану, позаду місто-паралакс пропливає, зверху капають XP/коїни. Метро — тунель з вогнями. Тяглість: вийшов → зібрався → на зупинку → поїхав → приїхав у нову сцену.
3. **Два види однієї сцени.** *Вид-сцена* (дефолт): ти всередині локації — повноекранне painterly-середовище, Гріндик-cutout поряд, зелений objective-glow на цілі, світла тепла картка завдання. *Вид-карта* (з неба): тап на «карту» → камера піднімається збоку вгору → шматок Києва з твоєю позначкою і маршрутом; пункти = піни-локації, не абстрактні орби.
4. **Акти = кар'єрний підйом.** Околиця/кімната/маршрутка (акт 1) → центр/Печерськ/люкс (акт 4). Середовище, транспорт, житло, заклади ростуть з гравцем.
5. **Персонаж живе у світі.** Модульний конструктор, гардероб за актом, домашня база апгрейдиться (один монітор → мультимонітор-риг), полиця трофеїв. Гріндик — ментор-cutout, підколює на переходах актів.
6. **Гейміфікація вплетена у світ.** XP/коїни/стрік/енергія — не лічильники збоку, а частина подорожі: квіз «всередині» локації, нагороди у сцені, objective-glow показує куди йти, серія вірних → золотий тінт на одязі.

**Коротко:** проходження курсу = подорож одним містом; кожен урок = зупинка, у яку приїхав; екран навчання = жива мапа Києва з маршрутом і переїздами, а не вертикальний ланцюг.

# ДОДАТОК А — Заголовок уроку (система з 3 трактувань)
Один компонент `<LessonTitle>` (одне місце в коді). CC обирає трактування авто за (а) довжиною назви, (б) шумністю фону. Завжди біла розділова обводка. Акцент — `#36e27a`. `fill/stroke` можна інвертувати під фон для контрасту (темний фон → світле тіло; світлий → темне тіло + біла обводка). `paint-order: stroke fill;` скрізь. Шрифти: **Russo One** (POP), **Oswald 700** (CAPS/PANEL) — обидва з кирилицею.

```css
/* T-POP — короткі/геройські назви, чистий фон */
font: 'Russo One'; font-size: clamp(30px,8vw,44px); transform: rotate(-3deg);
color: var(--accent,#ffce4d);
-webkit-text-stroke: 6px #fff;
filter: drop-shadow(2px 0 0 #000) drop-shadow(-2px 0 0 #000)
        drop-shadow(0 2px 0 #000) drop-shadow(0 -2px 0 #000)
        drop-shadow(5px 7px 0 rgba(0,0,0,.5));   /* чорний кейлайн + 3D-зсув */

/* T-CAPS — середні назви, помірний фон */
font: 'Oswald' 700; text-transform: uppercase; letter-spacing:.5px;
font-size: clamp(28px,7vw,40px); transform: skewX(-6deg);
color:#fff; -webkit-text-stroke: 4px #36e27a;
text-shadow: 0 0 16px rgba(54,226,122,.8), 3px 4px 0 rgba(0,0,0,.5);

/* T-PANEL — довгі назви / шумний фото-фон (найчитабельніше) */
/* текст */ font:'Oswald' 700; text-transform:uppercase; color:#fff;
            -webkit-text-stroke:3px #36e27a; text-shadow:0 0 16px rgba(54,226,122,.8);
/* плашка */ background:#111; border:3px solid #fff; transform:skewX(-6deg);
            box-shadow:6px 7px 0 rgba(0,0,0,.45), 0 0 0 3px #000;
/* хафтон плашки (::before) */ background-image:radial-gradient(rgba(54,226,122,.9) 1.3px,transparent 1.5px);
            background-size:8px 8px; opacity:.5;
```
**Правило вибору:** шумний/фото фон або довга назва → `T-PANEL`; чистий геройський кадр → `T-POP`; інше → `T-CAPS`.
**Правило контрасту:** якщо тіло зливається з фоном — інвертуй `fill` (світле↔темне), білу обводку лишай завжди.

# ДОДАТОК Б — технічні нотатки (де що лежить, як редагувати)

**Реалізація A–F (збірка b24).** Файли: `app-mvp/src/art/`.
- `levels.ts`: усі дані подорожі. `LOCS` = локація (плита, назва, ціль `goal`, ступні `feet`, зріст `h`, `cam`, поза). `MODULE_ROUTE[N][k]` = локація k-го уроку модуля N, `MODULE_HUB[N]` = де скриня золота. `ACTS` = 4 акти (транспорт, троль-репліки Гріндіка). `ALT_STAND` = інші точки підлоги, `standFor()` чергує точку й позу за номером уроку. `travelMode()` = чим їдемо.
- `stops.ts`: PATH → зупинки (`stopAt`, `currentStopIndex`, `travelBetween`).
- `Journey.tsx`: контейнер екрана «Уроки»: вид-сцена ↔ вид-карта (політ камери: perspective + rotateX), запуск переїзду, коли гравець пройшов урок і повернувся на екран.
- `StopScene.tsx`: вид-сцена: плита `cover` над карткою, Гріндік-cutout на `feet` з контактною тінню, РІВНО ОДИН `ObjectiveGlow` на `goal`, квіз-NPC на підлозі, скриня-cutout на цілі, заголовок, світла тепла картка, HUD.
- `JourneyMap.tsx`: вид-карта: SVG-Київ (Дніпро, парки, метро, райони), піни модулів, маршрут, Гріндік на поточному піні, список зупинок модуля (повтор).
- `Travel.tsx`: переїзд: 3 шари процедурного міста + дорога, транспорт-cutout за актом, тунель метро, XP/коїни, що капають (різниця `xp/coins` від моменту останнього приїзду зберігається в сторі як `journeyXp/journeyCoins`).
- `LessonTitle.tsx`: заголовок за Додатком А, SVG-шари (тінь → чорний кант → біла обводка → заливка), `pickVariant()` обирає POP/CAPS/PANEL.
- `Hud.tsx`: пігулки 🔥⭐🪙⚡.

**Правила підлоги.** `feet.y` ≤ 0.86 (картка закриває низ сцени), `|feet.x − goal.x|` ≤ ~0.2, щоб обидва були в кадрі. Усе в частках плити (0..1). Перевірка: у dev-збірці `http://localhost:8081/home?loc=<id>&alt=<n>` показує будь-яку локацію з потрібною точкою.

**Арт-пайплайн.** `npm run art:build`: транспорт `worlds/transport/*` → `cutout/transport/*`, скриня `fx/objects/chest_*` → `cutout/objects/*` (заливка фону від країв + найбільша компонента). Справжні шари глибини: покласти `worlds/layers/<плита>/bg|mid|fg.png`, лоадер `sceneLayers()` їх підхопить (зараз цільна плита + паралакс).

**Пастки.** (1) CSS `drop-shadow` на `<img>` RN-web малює темний прямокутник навколо прозорої фігури, тому `figureShadow()` на вебі вимкнено; заземлення дає контактна тінь. (2) Жорстка рамка `borderWidth` для нічної віньєтки теж малювала прямокутник, замінено градієнтом. (3) Windows: файли `Journey.tsx` і `journey.ts` конфліктують за регістром, логіку названо `stops.ts`. (4) Тип `Stop` конфліктує з `Stop` з react-native-svg, тип зупинки це `JStop`.

**З `WORLD_JOURNEY_SPEC.md` залишено.** Правило «усе, що торкається гравець, живе в координатах сцени, а не поверх картинки». Глибина: плита (повільно), актори (середнє), частинки/туман/світло за часом доби. Чесне обмеження арту: справжня глибина потребує шарів від художника.

**Прев'ю:** `EXPO_PUBLIC_*` прапорів для карти більше немає (стару карту видалено). Вимкнути Telegram/хмару: без змін.
