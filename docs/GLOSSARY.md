# Глосарій арбітражних термінів: uk → en, uk → ru

**Статус: чернетка на перевірку автору. Переклад контенту НЕ запускався.** Усі пари en/ru нижче складені Claude як пропозиція, нічого з них не затверджено. Перед наступним запуском `scripts/translate-content.mjs` цей список має стати глосарієм DeepL (див. рішення 1.6 у `docs/DECISIONS.md`).

Як зібрано: терміни взято зі словника застосунку (`app-mvp/src/data/glossary.ts`), модулів 01–10 (`content/modules/*.md`, `lessons.ts`, `module02.ts`) за частотою вживання. Колонка «Дія» така:

- **Перекладати**: у en/ru вживається звичайний переклад.
- **Лишати як є**: у цільовій мові це самостійний жаргон або абревіатура, перекладати не треба.
- **Адаптувати**: в en звичайний переклад, у ru лишається жаргонна форма (або навпаки). Деталі в пояснення.
- ⚠️ позначає ризикові терміни (див. `docs/RESTRICTED_IDS.md`): у публічній збірці їх нема, переклад потрібен лише для повної.

## 6. Для вирішення авторові

1. **Бренд у термінах**: «Fan Page / ФП», «Advantage+», «Audience Network», «Conversions API» це назви продуктів. Лишаємо їх як є, але не виносимо в назви курсу й застосунку.
2. **Єдина форма для ru**: у ru вживається і «оффер», і «офер», а також «баер» і «байер». Потрібне ваше рішення, яку форму брати.
3. **«Дофарм»** у en зараз перекладено як «Dopharm» (калька). Пропоную «account warm-up», але це ризикова тема, тож лише для повної збірки.
4. Терміни, яких у контенті не знайдено (наприклад «залив» як окреме слово), у список не включено. Якщо потрібні, додамо.
