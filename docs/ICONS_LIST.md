# Емодзі в інтерфейсі → іконки

Складено скануванням коду (`app/`, `src/`, без контенту уроків і каталогу карти кабінету). Мета: замінити емодзі єдиним набором 3D-іконок у стилі проєкту (`game-asset-dna`: матово-глянцевий «clay», верхнє світло, акцент `#36e27a`, нагороди `#ffce4d`).

**Статус заміни.** Іконки в застосунку замінюються лише там, де файл готовий і схвалений автором. Зараз у коді вже є картинки для 4 іконок: монета, стрік, XP, енергія (`src/components/Icon.tsx`). Решта лишається емодзі.

**Пропозиції проби** (дім, монета, енергія по 3 варіанти): `app-mvp/assets/icons/proposals/`, огляд: `docs/icon-proposals/trial-home-coin-energy.png`. У застосунок не підключені.

## Розміри

| Позначення | Де показується | Файл |
|---|---|---|
| **S** | 18–26 px (рядки списків, чипи, підписи) | PNG 512×512 з прозорістю (показ зменшується) |
| **M** | 28–36 px (вкладки, картки, квести, вертикалі) | PNG 512×512 |
| **L** | 40–56 px (ачівки, вузли, героєві блоки) | PNG 512×512 |

Усі файли 512×512 (як наявні `coin.png`, `energy.png`), ~10% полів, без запеченої тіні, прозорий фон. Один формат для S, M і L: зменшується в коді.
