## 1. Модульний конструктор персонажа (paper-doll)
- Персонаж = **база-архетип** (1 з 6) + шари: hair, skin-tone, top, bottom, shoes, outer, accessory (вкл. круглі окуляри).
- Рендер шарів у фіксованому z-порядку; кожен шар вирівняний під базу.
- Вибір/кастомізація юзером → зберігати в профілі (Supabase). Дефолт — пресети з `character/presets/`.
- **Grindik — окремий фіксований набір** (не конструктор).
- ⚠ Шарів одягу поки нема (гардероб — цілісні луки). Поки: пресети-луки як готові комбінації; інтерфейс конструктора будуй на шарах, але дай fallback на цілісний лук. Пошарові ассети прийдуть окремо.

## 2. Світ-у-щілині / паралакс
- Кожна сцена — **шари глибини** (fg/mid/bg), кожен ширший за екран (**overscan**).
- **Гіроскоп** (DeviceOrientation; у Telegram Mini App простіше) — зсув шарів з різною амплітудою.
- **Передній кадруючий шар** (рама вікна/одвірок) — найближчий; заголовки рівня «висять» поверх, можуть виходити за край.
- ⚠ Окремих шарів від арту поки нема → плейсхолдер: цілісна плита з легким zoom-паралаксом; архітектуру лоадера роби під майбутню заміну на fg/mid/bg.

## 3. Заставка рівня
- Композит: `worlds/splashes` (або `locations`) + **objective-glow** на цілі + точка старту + Grindik у позі.
- Мапінг рівень → локація + ціль (конфіг рівнів; заповнюється за модулями 01-10).
- Заголовок/опис завдання — overlay у стилі «висить у просторі».

## 4. Маркер цілі (objective green-glow)
- Reusable компонент: м'який зелений неон-ореол (soft bloom) на точці цілі. Параметри: позиція, радіус, інтенсивність, пульсація. Тон бренду **`#36e27a`**.

## 5. Система погоди/часу
- База-плита локації + **overlay-шари**: rain/snow/fog/overcast/night + **частинки** + **LUT** колоркорекція.
- Драйвер: **реальна погода Києва** через weather-API (дефолт Київ). Час доби — за годинником.
- Перемикання — рантайм, без перегенерації арту. Демо-кадри в `worlds/weather/` — як референс.

## 6. Банери в менюшках
- Промо/івент/інфо-банери в менюшках (магазин, головна, профіль): компонент-слот під painterly-банер + CTA.
- Дані банера (зображення, заголовок, дія, період показу) — конфіг/реміт, щоб міняти без релізу.
- Арт-банери прийдуть у `ui/banners/` (генерація окремо); поки — плейсхолдер-плити тих самих розмірів.

## 7. Анімація (ассети rig-ready)
- Персонажі — ізольовані, однаковий канвас → інтеграція **Spine/Rive**-рантайму для рігу/idle (пізніше, з аніматором).
- **Зараз:** статичні пози + прості tween-переходи + idle-погойдування як плейсхолдер. Передбач покадровий (flipbook) програвач — скоро прийдуть короткі серії кадрів для простих анімацій.

## 8. Порядок інтеграції (щоб не ламати поточне)
1. Структура `assets/art-v2/` + лоадер; підмінити старі плейсхолдери на нові статичні world/character.
2. Заставки рівнів зі статичним композитом + objective-glow.
3. Банери-слоти в менюшках (конфіг-кероване).
4. Паралакс (спершу zoom, далі шари) + гіроскоп.
5. Конструктор персонажа (пресети → повний).
6. Overlay погода/час.
7. Ріг/анімації (Spine/Rive + flipbook) — останнім, ітеративно.

## 9. Межі
- Claude Code = рантайм/інтеграція + плейсхолдери; арт постачається окремо.
- Жодного операційного контенту з обходу банів/мультиакаунтингу в застосунку (лише інформаційний рівень, як у decisions).
- Воєнні сцени — ambient, без жесті.
