# Реальна карта рекламного кабінету — фіча бібліотеки + список кадрів

Мета: новачок вчиться орієнтуватися в живому Ads Manager. У бібліотеці — анотовані скріни реального кабінету з українськими підписами-виносками.

---

## A. ТАСК ДЛЯ CLAUDE CODE (фіча)
```
Практичний шар, крок 2 — «Реальна карта рекламного кабінету» в бібліотеці.
1. Злий блоки «Нове · справжній скріншот» + «Карта кабінету» в ОДИН блок.
   Прибери підпис «Нове…». Заголовок: «Реальна карта рекламного кабінету.
   Навчися орієнтуватися».
2. Формат: горизонтальний стек/карусель із 7 екранів (нижче). Кожен екран =
   скрін кабінету + накладені виноски (callout-пін + коротка підказка укр).
   Виноски — дані, не захардкод у картинку: масив {x,y,text} поверх зображення,
   щоб редагувати без перезняття.
3. Скріни кладемо в app-mvp/assets/library/cabinet/*.png (я постачу). Поки їх
   нема — плейсхолдери з тими ж іменами, лейаут не чекає на арт.
4. Тап по екрану = фулскрін із читабельними виносками. Терміни у виносках
   лінкуй у Словник (той самий glossary).
Імена файлів і виноски — у секції B нижче. Не ламай: бібліотека, навігація.
Звіт: як влаштований блок, формат масиву виносок, імена-плейсхолдери.
```

---

## B. СПИСОК КАДРІВ (7) + українські підписи-виноски
Інтерфейс — українською. Кожен кадр — окремий екран карти.

**1. `01_structure.png` — рівень Кампанії (таблиця + вкладки)**
Виноски:
- «Три рівні: Кампанії → Групи оголошень → Оголошення. Перемикаєш тут.»
- «Статус показу: активна / вимкнено / на модерації / відхилено.»
- «Результат = скільки цільових дій. Ціна за результат = витрати ÷ результати.»
- «Бюджет і Витрачено — скільки дозволив і скільки вже пішло.»

**2. `02_adset.png` — рівень Групи оголошень (відкрита група)**
Виноски:
- «Тут вирішуєш: КОМУ (аудиторія), ДЕ (плейсменти), СКІЛЬКИ (бюджет), КОЛИ.»
- «Оптимізація та ставка — за що Facebook оптимізує й твоя контрольна ставка.»

**3. `03_ad.png` — рівень Оголошення (крео)**
Виноски:
- «Те, що бачить людина: медіа (фото/відео), текст, заголовок.»
- «Кнопка (CTA) і посилання на ленд.»

**4. `04_objective.png` — створення: вибір Цілі кампанії**
Виноски:
- «Ціль = що просиш у Facebook. Для заявок — Ліди; для продажів — Продажі.»
- «Від цілі залежить, кому система показує. Обирай під свою мету.»

**5. `05_budget_audience.png` — створення: група (бюджет + аудиторія + плейсменти)**
Виноски:
- «Бюджет: денний або на весь період.»
- «Аудиторія: гео, вік, інтереси або схожа (look-alike).»
- «Плейсменти: Advantage+ (автоматично) чи вручну.»

**6. `06_columns_breakdown.png` — Стовпці + Розбивка**
Виноски:

- «Розбивка: за віком/гео/плейсментом/часом — шукаєш, де працює, де злив.»

**7. `07_billing.png` — Налаштування платежів / білінг**
Виноски:
- «Платіжка, поріг білінгу (сума до списання), ліміт акаунта.»
- «Поріг зростає з довірою акаунта.»

> Зйомка: у Ads Manager українською (locale=uk_UA). Дані акаунта дормантні
> (товарка, кампанії вимкнені) — чутливого нема, але де видно назви оферів,
> можна лишати: це товарка, не ризик.
