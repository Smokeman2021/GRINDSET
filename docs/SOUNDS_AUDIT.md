# Аудит звуків

Є 7 синтезованих ефектів (`app-mvp/assets/sounds/*.wav`, `src/sound.ts`): `correct`, `wrong`, `crown`, `coin`, `levelup`, `tap`, `streak`. Нові звуки не створювалися, лише підключені наявні.

## Перевірка

Метод: у веб-превʼю перехоплено `HTMLMediaElement.prototype.play`, дії виконані кліками, зафіксовано, який файл відтворився. Те, що в телефоні звук реально чути, я не перевіряв (у середовищі нема динаміка).

## Що було і що стало

| Дія | Було | Стало | Перевірка |
|---|---|---|---|
| Правильна відповідь у уроці | `correct` | без змін | ✓ відтворився `correct.wav` |
| Хибна відповідь, таймаут | `wrong` | без змін | перевірено кодом (`record`, таймер), у превʼю лише правильну |
| Завершення уроку (екран результатів) | `correct` / `levelup` / `crown` | без змін | ✓ `correct.wav` |
| Корона пройдена | `crown` | без змін | перевірено кодом |
| Рівень підвищено | `levelup` | без змін | перевірено кодом |
| Тренажер кабінету (`/adsim`) | `correct` / `wrong` / `crown` | без змін | перевірено кодом |
| Покупка в магазині | `coin` | `coin`; **не вистачає коїнів → `wrong`**; повний запас / вже куплено → `tap` (було тихо) | ✓ `coin.wav` |
| Перемикання вкладок | **тиша** (`tap` не використовувався ніде) | `tap` на кожен тап по вкладці | ✓ `tap.wav` |
| Кнопка «Забрати нагороду» | **тиша** | `coin`, якщо є коїни | ✓ `coin.wav` |
| Стрік збільшився (перший урок за день) | **тиша** (`streak` не використовувався ніде) | `streak` через 0,7 с після основного звуку | ✓ `streak.wav` |
| Завдання дня: забрати нагороду | **тиша** | `coin` | перевірено кодом |
| Симулятор кампанії: підсумок | **тиша** | 3 зірки `crown`, 1–2 `correct`, 0 `wrong` | перевірено кодом |
| Перемикач «Звуки» в Налаштуваннях | вимикав нові звуки | вимикає все: нові не грають, ті, що вже звучать, обриваються (`stopAllSfx`); при вмиканні один `tap` | ✓ з вимкненим звуком тап по вкладці нічого не відтворив |

## Де тиша лишилась (не вимагалось)

- Звичайні кнопки застосунку (Button): без звуку. Можна додати `tap` у `Button.tsx` одним рядком, якщо потрібно.
- Вибір варіанта відповіді до натискання «Перевірити» і розкриття карток бібліотеки.
- Використання підказки, щита комбо, «X2» вікно, підвищення ліги, нова ачівка: окремих звуків немає, а наявні за змістом не підходять.
- Системні локальні сповіщення мають звук за налаштуванням системи, перемикач «Звуки» їх не торкається.
- На вебі браузер не програє звук до першого дотику користувача до сторінки.

## Де перемикач

Налаштування (шестерня в Профілі) → «Сповіщення і звук» → «Звуки». Стан `soundEnabled` у сторі, `playSfx()` перевіряє його перед кожним відтворенням.
