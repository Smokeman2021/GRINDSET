# 004 / 006 / 007 · Чек-лист після викладки b28 (через чинного бота)

Заповнює власник після кроків 9–11 плану вікна (після скидання). Позначки: ✓ / ✕ / коментар. Якщо щось не так — відгук з того самого екрана (контекст додасться сам). В Telegram один бот і один Mini App.

## Скидання (R1, R2, R4)

| Перевірка | Телефон | Telegram Desktop |
|---|---|---|
| **R1.** Учётка зі списку, основний пристрій: відкрити Mini App → чистий старт — онбординг, вибір персонажа, прогрес і монети з нуля; вхід без нового коду | | |
| **R2.** Той самий тестер на другому пристрої, де лишився старий прогрес: відкрити → пристрій очищено, теж чистий старт; старий прогрес не повернувся (на першому пристрої після оновлення — теж нуль) | | |
| **R4.** Якщо в когось лишилась стара збірка (b24): відкрити → вона нічого не записує; після переходу на b28 старого прогресу немає | | |
| Учётка **поза** списком: прогрес на місці | | |
| Учётка, відновлена з архіву (якщо відновлювали): прогрес повернувся, пристрій очистився й завантажив відновлене | | |

## Обовʼязково

| Перевірка | Телефон | Telegram Desktop |
|---|---|---|
| Вхід через бота; `https://trafik-lab.vercel.app/version.json` → `build 28` (у застосунку номер збірки бачить лише dev-збірка) | | |
| Запуск через бота відкриває головну з «▶ Продовжити» (а не останній екран) | | |
| Головна «Обери вертикаль»: 8 карток, у регульованих «фінал: рішення про допуск» | | |
| Перший вхід в урок гілки: сцена закладу Києва → «Увійти» → урок; повторний вхід — одразу урок | | |
| Пройти урок до результату (нагорода показана) → «Карта: що відкрилось» → переїзд з «Освоєно · Відкрилось» → карта | | |
| Закрити Mini App посеред уроку → відкрити → «▶ Продовжити» веде на той самий крок; є «Почати заново» | | |
| Другий пристрій тим самим тестером: той самий прогрес і «Продовжити» | | |
| Відгук з уроку: в адмінці видно екран, урок і крок | | |

## Далі

| Перевірка | Телефон | Telegram Desktop |
|---|---|---|
| **Мінус на iOS:** числове поле — кнопка «±» біля поля ставить і прибирає мінус; ввести −48 і 33,1 (кома); клавіатура однакова для всіх полів; плейсхолдер «0» | | — |
| **Пряме посилання / перезавантаження:** у Mini App потягнути сторінку вниз (перезавантаження) на статті «Бази», в уроці, у тренажері — відкривається той самий екран після входу | | |
| **Недійсне посилання** (на Desktop: у веб-версії ввести `/lesson/BR-TOV-L99`) → «Посилання не відкривається» з кнопкою «До навчання» | — | |
| **Статус несинхронізованої операції:** штучно не відтворюється; якщо на головній зʼявився «⚠ Частину прогресу ще не синхронізовано» — натиснути «Повідомити» й надіслати відгук | | |
| **🐞 на темній темі:** кнопку видно (рамка), вона в межах колонки й не накриває бульбашку Гріндіка, показники, HUD сцени | | |
| **Пари на телефоні:** дві колонки, номер пари на обох картках, довгі назви переносяться, повторний дотик знімає пару; до «Перевірити» кнопки «Далі» немає (і MainButton Telegram прихована); «Додати своє пояснення» розкривається за дотиком | | |
| **Сцени переходів:** сцена закладу перед уроком, переїзд (транспорт, «Освоєно · Відкрилось»), тап пропускає; новий акт показується лише при русі вперед; «Карта» зі сцени повертає на карту гілки; у картці точки — «🎬 Переглянути сцену закладу» | | |
| Товарка: уроки 1–5 → тренажер «Ліди»: розбір відкривається після першої спроби; з невиконаним обовʼязковим критерієм кнопка «Виправ обовʼязкові критерії» вимкнена; «Пройти крок ще раз» → назад до розбору → «Завершити тренажер» | | |
| «Ліди», варіант Б: пояснення й питання «Що змінює варіант Б?» | | |
| Тренажер: закрити на кроці → «Продовжити» → той самий крок | | |
| Самоперевірка: закрити на 2-му питанні → «Продовжити» → той самий крок | | |
| Вісім гілок обома шляхами: «Почати з основ» і «Перевірити себе» | | |
| Регульована гілка: плашка «Підтвердженого правила майданчика для цього випадку немає…»; фінал з відповіддю «запускати» не зараховується | | |
| Термін у тексті → підказка → стаття «Бази» → «Назад» на той самий крок | | |
| «Продовжити» зі статті «Бази» → «← Повернутись: урок» | | |
| «База»: гайди GDE, кейс CASE-13 (ключ — після спроби), INS-02/03 з переходом до калькуляторів | | |
| Тестер RU/EN відкриває гілку українською | | |
| Адмінка: вкладки в один рядок (прокрутка), «в черзі для Claude», ⭐, помітка, «Черга для Claude (Markdown)», «Внесок» | | |
