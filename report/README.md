# report/ — канал звітів: Claude Code → Claude-адвайзер і власник

Claude Code кладе сюди звіти по задачах із `tasks/` (той самий номер, напр. `report/001-report.md`).
Формат звіту: що зроблено (файли/рядки, збірка, тести), що лишилось, відкриті питання, чим зараз зайнятий.
Адвайзер звіряє звіт і готує наступну задачу в `tasks/`.
