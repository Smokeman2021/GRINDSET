# GRINDSET — Арт-бриф персонажа «Гріндік»
> Для художника / 3D-артиста / AI-генерації концепту. Дата: 03.06.2026.

## Хто це
Гріндік — маскот і компаньйон у застосунку (не вчитель). Свій хлопець, який сам пройшов шлях від повного нуля до профі в медіабаїнгу. Самоіронічний, зухвалий, але **підтримує**, а не глузує. Голос: коротко, по суті, з гумором.

## Цільовий візуальний стиль
Стилізований **3D-CGI** маскот рівня мобільної гри / анімації (вайб Pixar-clay, не фотореалізм людини). Чисті об'ємні форми, м'яке студійне світло, виразна міміка. Має читатись на маленькому екрані телефона. НЕ реалістична людина, НЕ аніме, НЕ плоский флет.

## Зовнішність (канон)
- Худі (толстовка) — головний елемент, фірмовий **зелений** (#36e27a) як акцент.
- Статура звичайна, молодий хлопець, 20-25 на вигляд.
- Сигнатурна деталь: **сонцезахисні окуляри** (для «впевнених» станів). Золоті окуляри — ексклюзивна нагорода, не базові.
- Палітра: фон темний (#0d0f14), шкіра тепла, акцент зелений, золото (#ffce4d) для нагород, помаранчевий (#ff7a3c) для «вогню/комбо».

## Еволюція (стадії — фінальну кількість ще фіксуємо, орієнтир 7)
Персонаж буквально росте разом з прогресом гравця:
1. Неандерталець — розтріпаний, без кави, нуль розуміння.
2. Гомо Сапієнс — трохи охайніший, щось читав.
3. Ранній Цивілізатор — є базовий сетап.
4-6. Поступово: впевненіший, кращий одяг, налаштоване робоче місце.
7. Junior-профі — зібраний, впевнений, «реально вміє».
> Кожна стадія = той самий персонаж, але видно зростання (одяг, поза, оточення, впевненість).

## Набір емоцій/анімацій (мінімум для MVP)
Це те, що вже реалізовано як стани в коді — їх треба замінити на CGI:
- Спокій / нейтрально (база, в окулярах).
- Радість — вірна відповідь.
- Вогонь/азарт — серія вірних (комбо 🔥).
- Замислений — під час теорії / складної задачі.
- Спантеличений — помилка. **Важливо: спантеличений/підбадьорливий, НЕ насмішкуватий.**
Бонус (пізніше): вітання в онбордингу, святкування рівня, idle-дихання.

## Технічна доставка для застосунку (критично)
Застосунок **не рендерить 3D наживо**. Потрібні готові ассети:
- **Варіант А (рекоменд.):** анімації експортувати в **Lottie (JSON)** — легкі, векторні, плавні на всіх телефонах.
- **Варіант Б:** послідовності кадрів PNG (sprite sheets), прозорий фон, @1x/@2x/@3x.
- **Варіант В (тільки якщо треба обертати):** 3D-модель glTF + рендер у react-three-fiber. Дорожче по продуктивності — для MVP не треба.
- Прозорий фон, квадратний кадр, персонаж по центру з полями.

## Чого НЕ робити
- Не висміювати користувача (жодних принизливих жестів на помилку).
- Нічого, що тригерить модерацію сторів: без алкоголю/гемблінгу/зброї, без обіцянок «легких грошей» на самому персонажі.
- Без зайвих дрібних деталей, що зникнуть на маленькому екрані.

## Пайплайн і інструменти (на вибір)
- Концепт-арт: Midjourney / DALL·E (2D-референс пози й стилю).
- 3D-модель: Blender (вручну) або AI-3D (Meshy, Luma) з концепту.
- Анімація → Lottie: After Effects + Bodymovin, або готові 3D-рендери в кадри.
- Бюджетний старт: один художник-ілюстратор робить 2.5D-версію (об'ємний вигляд без повного 3D) + прості Lottie.

## Сід-промпт для AI-концепту (стартова точка)
> "3D stylized mascot character, young guy in a green hoodie, cool sunglasses, friendly confident smirk, Pixar-like clean shapes, soft studio lighting, dark background, mobile game mascot, full body, centered, transparent background"
Далі ітеруємо під кожну стадію та емоцію.

## Що далі
1. Затвердити стиль UI (з трьох варіантів) — щоб персонаж пасував до інтерфейсу.
2. Зробити концепт 1 стадії + 1 емоції, погодити вигляд.
3. Розкатати решту стадій/емоцій.
4. Експорт у Lottie → підміна заглушок у коді (код міняти майже не треба, персонаж — окремий шар).
