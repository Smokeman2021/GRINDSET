# GRINDSET — Методологія роботи з Facebook рекламою
## (Витягнуто з досвіду автора + систематизовано)

> Подається в курсі як стандарт індустрії, не як авторська методологія.
> Джерело: 11 років практики в арбітражі трафіку Facebook.

---

## АНАЛІТИКА АДСЕТІВ

### Правило 2 днів
Два дні поспіль без лідів → перевіряти / переробляти / перезапускати.
Не вимикати після першого невдалого дня — алгоритм пристрілюється.

### Автоправило 00:00
Вимкнути адсет якщо немає ліда до певної суми витрат.
Увімкнути о 00:00 для нового старту.

### Гранична вартість ліда
- Якщо перший лід прийшов на $3 → докручуєш до $3.5
- Якщо другий не прийшов — вимикаєш
- Якщо перший на $2.5 → наступний має прийти на $5-5.5 (ціновий трейлер)

### Загальні правила:
- Аналіз в розрізі 2-3 днів, не одного
- Перший день часто без лідів — норма
- Не давати адсету відкрутити повний денний бюджет якщо немає лідів
- Нецільові ліди — вимикати одразу

## МАСШТАБУВАННЯ

### За типом товару:
| Тип | Підхід |
|-----|--------|
| Наливаторський (ліди до $1.5) | Можна підняти бюджет вдвічі |
| Не наливаторський | Раз на 2 дні, +10-20% максимум |

### Принципи:
- Масштаб акаунтами: та сама зв'язка на нових акаунтах
- Не чіпай те що вже працює. Хочеш тестувати — в іншому кабінеті
- Дублі кампаній = новий запуск у навчанні (не масштабування)
- НЕ підвищувати бюджет без аналізу і розуміння на скільки

## БІЛІНГ ТА ФІНАНСОВІ ТЕРМІНИ

### Розділяти два поняття:
- **Поріг витрат (денний ліміт)** — встановлює Facebook на основі трасту акаунту
- **Поріг білінгу** — сума при якій відбувається фактичне списання з карти

### Градація порогу білінгу:
Починається з мікробілінгів (~$2), поступово зростає з кожним успішним списанням.
Орієнтовна градація: $2 → $3 → $5 → $7 → $10 → $12 → $15 → $20 → $25 → $50 → $75 → $125 → $150 → $175 → $200 → ... → $900 (максимум).
Офіційно Meta не публікує таблицю — це практика з досвіду.

**При невдалих списаннях:** поріг знижується.

### Реальний підрахунок прибутку:
Виплата з партнерки − Витрати на рекламу (від'ємаються при досягненні порогу білінгу, не одразу) = Реальний заробіток.
Важливо враховувати що оплата реклами відкладена до досягнення порогу або певної дати.

## АКАУНТИ

### Власний акаунт:
- Це мегатрастовий актив. Новачку — не використовувати для реклами
- Зберегти для: досвідченої роботи, особистого бренду, власного бізнесу
- Якщо соціальний акаунт забанять → весь Business Manager може впасти разом

### Дофарм купленого акаунту:
НЕ фарм у класичному сенсі. Це процес безпечного старту з новим купленим акаунтом.
Мета: дати алгоритму FB зрозуміти що акаунт живий і людський перед запуском реклами.

## РЕЖИМ РОБОТИ

- Пікові години для аналізу: 16:00-20:00

## КРЕО ТА ОГОЛОШЕННЯ

### Кількість оголошень в адсеті:
Якщо в адсеті більше одного оголошення — бюджет розподіляється нерівномірно.
Йде туди де відбулись перші дії або де Facebook вже знає результативність крео.

### Відеомонтаж:
DaVinci Resolve (не Camtasia)

## АВТОНОМНИЙ БАЄР — КОМПЕТЕНЦІЇ

Хороший баєр вміє не тільки запускати рекламу. Автономний баєр:
- Робить креативи самостійно (дизайн + монтаж)
- Пише продаючі тексти (AIDA та інші)
- Створює базові сайти на конструкторах
- Базово орієнтується в HTML: знайти потрібний елемент, витягнути медіа з захищеного сайту
- Базово фармить/дофармить акаунти
- Розуміє поведінкову психологію для алгоритмів FB
- Базово знає AI: промптинг (ChatGPT, Midjourney)

## СТРУКТУРА БІЗНЕС-МЕНЕДЖЕРА

**Ієрархія (розуміти чітко):**
```
Особистий профіль Facebook
    └── Business Manager (може бути кілька)
            ├── Рекламний акаунт (де запускається реклама)
            ├── Фан-сторінка (потрібна для показу реклами)
            └── Піксель (збирає дані, прив'язується до акаунту)
```

**Events Manager vs Піксель:**
- Піксель = інструмент збору даних
- Events Manager = інтерфейс для управління пікселями та їх подіями
- Якщо піксель прив'язаний правильно → конверсії фіксуються в кабінеті

## ПАРТНЕРСЬКІ МЕРЕЖІ

- Менеджер партнерки — важливий союзник. Комунікувати активно
- Перший офер: починати з товарки, гео що знайоме
- Апруви, виплата, обмеження — аналізувати перед стартом
- Нецільові ліди можуть знизити апруви → моніторити
