## 2. ДІАГНОСТИЧНИЙ ТЕСТ (після квізу)

10-15 питань. Мікс типів завдань.
Якщо пропустити — автоматично базовий трек для початківців.

### Сценарії після тесту:

**Сценарій A** — Квіз і тест збігаються → система формує трек без питань.

**Сценарій B** — Розбіжність (сказав новачок, тест показав інше):
*"Ти казав що нічого не знаєш, але тест пройшов непогано."*
Вибір:
- Пройти з початку — хочу міцну базу
- Перейти на рівень [X] — вже знаю основи
- Пройти складніший тест — визначити точний рівень

**Сценарій C** — Складніший тест (якщо обрав) — ще 10-15 питань.

### Ачівка за бездоганний тест:
- Умова: перший тест, з першої спроби, без помилок
- Нагорода: 😎 Золоті сонцезахисні окуляри (ексклюзивно, іншим способом — неможливо)

## 4. СИСТЕМА ЕНЕРГІЇ

- **Максимум:** 50 одиниць
- **1 урок** = 10 енергії → 5 уроків на день без поповнення
- **Відновлення:** +10 кожні 4 години автоматично
- **Щоденний вхід:** +10 бонус
- **Перегляд реклами:** +5 (до 3 разів/день = +15 максимум)
- **Підписка:** необмежена енергія

**При 0 енергії:**
- ❌ Новий урок — заблоковано
- ✅ Повтор пройденого уроку — доступно (з бонусом)
- ✅ Теорія по пройденому матеріалу — доступно

**Бонус за повтор:**
- Краще ніж минулого разу → +коїни
- Без помилок → +XP бонус
- Швидше → ачівка "Спідран"

## 5. МЕХАНІКА УРОКІВ

### Структура уроку:
- Кожен курс складається з рівнів (як Duolingo)
- Кожен рівень = 4 етапи (закріплення / доповнення / пояснення)

### Типи завдань:
- Тест (множинний вибір)
- Drag & Drop
- Вписати слово
- Взаємодія з симуляцією Ads Manager (статика + анімація)

### Прогрес-бар:
- Смужка заповнюється по ходу
- Помилки → червоне заповнення на тому етапі де була помилка

### Реакції персонажа:
- **Помилка:** сміється / палець вниз / схрещує руки і відвертається (різні анімації, без повторень)
- **Правильна відповідь:** палець вгору / "ростеш, красава" / інші мотивуючі реакції
- Рівень позитивності/азарту персонажа росте при серії правильних відповідей

### Комбо-система:
- Комбо росте за кожну правильну відповідь підряд
- Бонус: **+2% → +20%** до фінальної винагороди
- Максимум — якщо всі рівні пройдені ідеально
- **Згорання:** невірна відповідь → комбо обнуляється
- **Захист:** 2 згорання за урок можна відмінити переглядом реклами
- Після 2 захистів — комбо горить до кінця уроку

### Два шари кожного уроку:
**Шар 1 — Розуміння:** Коротко, просто, приклад. Тест / drag&drop / вписати.
**Шар 2 — Застосування:** Сценарна задача з реальними цифрами. "Ось ситуація — що робиш?"

### Фінальний екран уроку:
- Рівень заповнюється
- Статистика: помилки / вірні відповіді / що уточнити
- Зароблені коїни
- Рейтинг: порівняння з іншими (швидкість + результативність)
- Анонс наступного уроку

## 6. ПЕРСОНАЖ — ГРІНДІК

### Концепція:
Свій хлопець у худі + самоіронічний гумор (тип A + елементи C).
Компаньйон, не вчитель. Пройшов весь шлях від неандертальця до про.

### Стартові стани після квізу:
| Результат | Персонаж |
|-----------|---------|
| Новачок | 🦴 Неандерталець |
| Базові знання | 🧠 Гомо Сапієнс |
| Досвідчений | ⚡ Ранній Цивілізатор |

### Еволюція (7-10 стадій):
Персонаж буквально "розвивається" разом з прогресом. Від розтріпаного без кави — до впевненого з налаштованим сетапом.

### Профіль персонажа:
| Поле | Приклад |
|------|---------|
| Ім'я | Задається користувачем |
| Рівень | Lvl 3 — "Той що злив перший бюджет" |
| Потенційний дохід | Динамічний |
| Статус | Генерується з мемів арбітражу |

### Приклади назв рівнів:
- Lvl 1 — "Щойно дізнався що є арбітраж"
- Lvl 2 — "Вже читав про це в телеграмі"
- Lvl 3 — "Злив перший бюджет на навчання"
- Lvl 5 — "Розібрався з пікселем з третього разу"
- Lvl 7 — "Перший плюс. Мама пишається"
- Lvl 9 — "Фармить акаунти у вихідні"
- Lvl 10 — "Junior. Реально вміє"

## 12. БІБЛІОТЕКА ЗАСТОСУНКУ

Окремий розділ у Grindset — не частина курсу.
Містить картки інструментів: Назва / Для чого / Ціна / Плюси / Мінуси.
На ці картки ведуть зноски з уроків при згадці ключових слів (трекер, антидетект тощо).
Оновлюється незалежно від курсу.

**Категорії бібліотеки:**

- Антидетект браузери
