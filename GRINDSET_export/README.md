## ПРИНЦИПИ РОБОТИ

### Контент:
- Не персоналізувати як "авторська методологія" — подавати як стандарт індустрії
- Приклади — реальні, з реальними цифрами, без хибних спрощень
- Уроки короткі (5-10 хв читання/проходження)
- Структура: Шар 1 (розуміння) + Шар 2 (сценарна задача)
- Зноски на Бібліотеку при згадці ключових слів

### Технічна частина:
- Стек: Next.js / React Native / Node.js / Supabase / Claude API
- Архітектура агентів через Supabase (таблиці вже створено)
- API ключі — тільки env variables

### Що не потрібно:
- Довгі вступи і вступні слова
- "Звісно!", "Відмінно!", "Чудово!"
- Перепитувати те що вже є в контексті
- Пропонувати курси Anthropic (їх не існує)
