# GRINDSET — MVP Spec (зафіксовані рішення)
> Дата: 03.06.2026. Це закон для першої версії. Все, що не тут — заморожено до валідації retention.

---

## СТЕК (фінально)
- **Expo (React Native) + expo-router + TypeScript** — один кодбейс, веб отримуємо через react-native-web безкоштовно.
- Стан: легкий store на Zustand (без бекенду в MVP).
- Дані: локально (AsyncStorage). Supabase підключаємо ПІСЛЯ валідації.
- Next.js окремо — НЕ робимо. Якщо треба лендінг — пізніше, окремо.
- Агентна система (`agent_*` таблиці, manager) — **заморожено**. Ролі Контент/Розробка/Стратегія ведемо через Cowork.

## МОВА / AUTH (MVP)
- Мова: **UA only**. i18n-структура закладена (легко додати EN/RU потім), але переклади не робимо.
- Auth: **тільки Google** (заглушка в MVP — вхід без бекенду, локальний профіль). FB/Telegram — потім.

## ПОЗИЦІОНУВАННЯ (store-safe)
- Продукт = **освіта з performance-маркетингу / медіабаїнгу**. НЕ «заробіток», НЕ «заміна інфоциган» у сторі.
- **Прибрано з MVP:** Модуль 09 (куплені акаунти, дофарм, антидетект, обхід банів), «потенційний дохід» у профілі, будь-які обіцянки заробітку.
- Сценарні задачі показують і **збитки** (перший запуск часто в мінус) — це чесно і знижує «get-rich» сигнал для модерації.
- Дисклеймер в онбордингу: навчальний контент, не фінансова порада, не гарантія доходу.

## ЕКОНОМІКА ЕНЕРГІЇ (одна модель, без протиріч)
- **Баланс енергії: стеля 50.** Це максимум, не денна видача.
- 1 урок = **10 енергії** (5 уроків поспіль з повного балансу).
- Відновлення: **+10 кожні 4 години** до стелі 50.
- Щоденний вхід: **+10** (понад стелю не складується більше 50 → бонус діє коли баланс < 50).
- Реклама/підписка в MVP **вимкнені** (немає монетизації). Енергія в MVP — м'яка: при 0 показуємо «відпочинь або повтори», уроки не блокуємо жорстко (мета MVP — retention, не монетизація).

## КОМБО (як у прототипі)
- +1 за кожну вірну поспіль. Бонус до нагороди: +2% за крок, стеля +20%.
- Помилка → комбо в нуль. Захист комбо рекламою — **поза MVP**.

## СКОУП MVP (рівно це, не більше)
Робимо:
1. Онбординг-квіз (6 кроків) + ім'я персонажа + дисклеймер.
2. Один модуль — **Модуль 01, 7 уроків**, шари 1+2.
3. Гріндік: стартові стани + реакції на відповіді (підтримуючі, не глузливі).
4. Streak + коїни (лічильники, без магазину).
5. Шлях уроків (Duolingo-стиль), екран результатів зі статистикою.
6. Локальне збереження прогресу.

НЕ робимо в MVP: підписки, реклама, магазин, ліги/рейтинг, бібліотека, мульти-мова, мульти-auth, адаптивні гілки тесту, бекенд, агенти.

## ГОЛОС ПЕРСОНАЖА
- Зухвалий, свій хлопець, самоіронія. **Не глузує з користувача за помилки.** Помилка → «буває, дивись як треба», не «ха-ха лох».

## КРИТЕРІЙ УСПІХУ MVP
Не гроші. Питання: **чи доходять люди до кінця Модуля 01?** Тест на 20-50 людях. Якщо completion слабкий — чинимо контент/UX, а не будуємо монетизацію.
