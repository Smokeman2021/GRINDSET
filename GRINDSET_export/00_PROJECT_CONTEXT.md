## ЩО ЦЕ ЗА ПРОЕКТ

**GRINDSET** — мобільний EdTech додаток для навчання арбітражу трафіку Facebook/Instagram/TikTok.  
Аналог Duolingo, але для медіабаєрів.

**Автор:** Ioan (11 років досвіду в арбітражі трафіку Facebook)  
**Статус:** Фаза проектування + початок розробки  
**Мови додатку:** UA / RU / EN (i18n з першого дня)

---

## ЦІЛЬ ПРОДУКТУ

Після проходження людина має отримати рівень **Junior+** (до Middle якщо проходила додаткові матеріали).  
Замінює платні курси від інфоциган. Повноцінне навчання під ключ.

**Перший курс:** Арбітраж трафіку Facebook (товарка як демо-вертикаль)  
**Далі:** Окремі курси по Instagram, TikTok, всіх вертикалях

## АГЕНТНА СИСТЕМА

Мета: мінімізувати менеджмент з боку Ioan, максимізувати автономність команди агентів.

**Архітектура:**
```
Ioan → задача/корективи
         ↓
Агент-менеджер (читає Supabase, розподіляє задачі)
         ↓
Агент-контент + Агент-розробка + Агент-стратегія
         ↓
Результати записуються назад у Supabase
```

**Статус:** Структура таблиць готова, перший агент-менеджер написаний.
