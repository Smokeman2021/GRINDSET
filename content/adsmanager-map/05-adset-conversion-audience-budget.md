# Екран: Створення кампанії — крок 3, група оголошень (конверсія, аудиторія, бюджет)

Той самий діалог, ліва колонка дерева підсвічує рядок «Група оголошень», форма по центру міняється.

## Розділ «Конверсія» (✅, згортається)
- **Місце отримання конверсій**: випадний список (за замовчуванням «Моментальні форми»; інші варіанти — сайт, дзвінки, месенджер тощо)
- **Сторінка Facebook**: випадний список вибору сторінки (з іконкою-аватаром сторінки) + назва
  - Інформаційна картка: «Ви прийняли умови використання реклами для збору лідів на платформах Meta для цієї Сторінки» + посилання «Умови» + кнопка закрити (✕)
- **Профіль Instagram**: випадний список (автопідставляється повʼязаний акаунт)
- **Ціль по результативності**: випадний список (за замовчуванням «Максимальне число лідів»)
- **Ціль по ціні за результат**: «Немає» (поле для введення суми, якщо потрібно)
- **Правила визначення цінності**: «Включено: немає»
- Посилання «Ще параметри ▾»
- **Динамічні креативи**: перемикач Викл./Увімк.

## Розділ «Бюджет і графік» (✅)
- Бюджетна стратегія: пояснювальний текст, що бюджет кампанії розподіляється автоматично; посилання «Про ліміти витрат»
- **Ліміти витрат для групи оголошень**: «Нічого не додано» (можна задати)
- **Запланувати**:
  - Дата початку: календар-піфкер (дата) + окреме поле часу (година:хвилина, часовий пояс GMT+3)
  - Дата завершення: «Встановити дату закінчення» (перемикач/посилання)
  - Посилання «Показати більше налаштувань»

## Розділ «Аудиторія» (✅)
- Перемикач «Параметр Advantage+ увімкнено» + опис: «Налаштуйте аудиторію за допомогою обмежень і рекомендацій»
- **Використовуйте збережену аудиторію**: випадний список «Керування»
- Підказка: «Ми не будемо охоплювати людей поза цими налаштуваннями навіть при увімкненому параметрі Advantage+»
- **Місцезнаходження**: «Включено: Україна» (редагується, мультивибір країн/міст/радіусу)
- Посилання «Показати додаткові засоби налаштування» (стать, вік, мова — приховано за замовчуванням)
- **Порекомендуйте аудиторію** (розширення Advantage+):
  - Пояснення: «Ми будемо охоплювати людей поза цими налаштуваннями, коли це може покращити результативність»
  - «Включити ці користувацькі аудиторії»: мультивибір
  - «Включити людей, які входять хоча б в одну з наступних категорій»: кнопка «Створити», посилання «Показати рекомендації»
  - Перемикач «Обмежити охоплення реклами ще більше»
- Кнопка/посилання «Зберегти аудиторію»

## Права панель (та сама, що на екрані 04) додатково показує
- **Прогнозований розмір аудиторії**: смуга-індикатор + діапазон чисел (напр. «16 700 000 – 19 700 000»), підказка: «Прогнози не враховують можливості аудиторії Advantage+ і з часом можуть суттєво змінюватися»
- Якщо в акаунта є обмеження: червона картка «Перевірте 1 помилку» → розгортається текст «На ваш акаунт зараз накладені обмеження: це дія тимчасово заблокована для вас. (#код)» + посилання «Детальніше»

## Дерево зліва
Рядок групи оголошень отримує іконку «⊘» (заборонено) поруч, якщо на акаунті є обмеження публікації — суто візуальний індикатор статусу, сама форма лишається редагованою.
