# Екран: Events Manager (огляд, піксель/наборы даних)

URL: `eventsmanager.facebook.com/events_manager2/overview` (окремий піддомен, не `adsmanager.facebook.com`; заходять через пункт «Events Manager» у лівому рейлі Ads Manager)

## Верхня панель
- Заголовок зліва: «Огляд Events Manager»
- Перемикач акаунта: іконка бізнесу + назва акаунта (з ID у дужках)

## Ліва бічна панель розділу
Вертикальний список:
- ➕ Підключити дані
- ⊞ Огляд (активний, підсвічений)
- 👥 Набори даних
- ⭐ Спеціально настроєні конверсії
- 🔌 Інтеграції
Кнопка згортання рейла внизу (стрілки «‹›»)

## Порожній стан (немає підключеного пікселя/набору даних)
Велика картка на всю ширину контенту, ілюстрація праворуч (люди з лупою й іконками магазину — фірмовий стиль Meta, жовто-фіолетова графіка):
- Заголовок «Ласкаво просимо в Events Manager»
- Підпис «Налаштуйте інструменти для бізнесу, щоб оптимізувати результативність реклами»
- Три пункти зі своїми іконками:
  1. 🔗 «Підключення даних» — «Налаштуйте підходящі інструменти для бізнесу, щоб ділитися даними сайтів, застосунків, серверів і магазинів»
  2. 📈 «Отримуйте корисну статистику для вашої компанії» — «Вимірюйте дії, які люди виконують після взаємодії з вашим брендом»
  3. 🎯 «Оптимізуйте рекламу для отримання реальних результатів» — «Визначайте цінних клієнтів і показуйте рекламу тим, хто з найбільшою ймовірністю виконає конверсію»
- Кнопка «Підключити дані» (синя, заповнена) — двічі на екрані: у самій картці знизу і як CTA біля ілюстрації

## Навчальний контекст (чому цей екран важливий)
Це стартова точка теми «піксель і трекінг подій» — курс уже пояснює, що трекер/піксель не бачить конверсій (мем m-quiz), тож корисно показати студенту, що насправді значить «підключити піксель»: це один конкретний синій CTA на порожньому екрані, а не щось містичне. Кандидат для кроку-скріншота в уроці про аналітику/пиксель (модуль про метрики).

## Кольори
Фон сторінки: той самий блідий рожево-блакитний градієнт, що й на «Рахунки й оплата» (відрізняється від чисто білого фону «Кампанії»/«Створення кампанії») — схоже, всі «порожні»/онбордингові екрани акаунта використовують цей градієнт, тоді як робочі таблиці — білий фон.
