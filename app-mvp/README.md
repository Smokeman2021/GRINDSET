# GRINDSET — MVP (Expo)

Перша робоча версія. Скоуп — за `08_MVP_SPEC.md`: онбординг + Модуль 01 (7 уроків) + Гріндік + streak/коїни. Локально, без бекенду.

## Стек
Expo (React Native) + expo-router + TypeScript + Zustand. Веб працює через react-native-web з тієї ж кодової бази.

## Як запустити (один раз постав Node 18+)
```bash
cd app-mvp
npm install
npx expo install --fix   # підрівняти версії під SDK (рекомендовано)
npx expo start
```
Далі:
- Телефон: постав застосунок **Expo Go**, скануй QR з терміналу.
- Веб: натисни `w` у терміналі (відкриє браузер).
- Емулятор: `a` (Android) / `i` (iOS, лише macOS).

Скинути прогрес: видали застосунок з Expo Go і запусти знову (стан зберігається локально).

## Структура
```
app/
  _layout.tsx        навігація (Stack, темна тема)
  index.tsx          роутинг: онбординг чи головна
  onboarding.tsx     квіз (6 кроків) + ім'я + дисклеймер
  home.tsx           шлях уроків + топ-бар (streak/коїни/енергія)
  lesson/[id].tsx    рушій уроку: шари 1/2, комбо, реакції
  results.tsx        підсумок: статистика, нагорода, наступний урок
src/
  data/quiz.ts       питання онбордингу
  data/lessons.ts    КОНТЕНТ Модуля 01 (7 уроків) — редагуй тут
  store.ts           стан + збереження (AsyncStorage)
  theme.ts           кольори + стани персонажа
  components/        Grindyk, Button
```

## Як додавати контент
Весь курс — це дані. Щоб додати/змінити урок, редагуй `src/data/lessons.ts`.
Кожен крок — `choice` (вибір) або `fill` (вписати), з полем `layer` (1 — розуміння, 2 — застосування), `answer`, `okMsg`, `noMsg`, опційно `explain`. Код екранів чіпати не треба.

## Що далі (поза MVP, за спекою)
Supabase (синхронізація прогресу), реальний Google-auth, підписки (RevenueCat), магазин/ліги, мульти-мова. Додаємо ПІСЛЯ перевірки retention на Модулі 01.

## Заглушки
- Гріндік — емодзі-плейсхолдери (`src/theme.ts` → `GR`). Заміна на SVG/Lottie — окрема задача.
- Auth у MVP немає: профіль локальний.
- Енергія м'яка: уроки не блокуються жорстко (мета MVP — retention).
