# Design Workflow

## Backward Design Workflow (3-Stage Process)

### Stage 1: Identify Desired Results
1. Define learning goals aligned to standards
2. Write measurable learning objectives (Bloom's taxonomy verbs)
3. Identify essential questions and enduring understandings
4. Determine what students should know, understand, and be able to do

### Stage 2: Determine Assessment Evidence
1. Design summative assessments that measure stated objectives
2. Create performance tasks and authentic assessments
3. Develop formative assessment checkpoints
4. Establish success criteria and rubrics

### Stage 3: Plan Learning Experiences
1. Select instructional strategies aligned to objectives and assessments
2. Sequence content from simple to complex (scaffolding)
3. Apply UDL principles — provide multiple means of:
   - Representation (how content is presented)
   - Action & Expression (how students demonstrate learning)
   - Engagement (how students are motivated)
4. Build in feedback loops and opportunities for revision

## Quality Assurance Checklist

- [ ] Objectives are measurable and student-centered
- [ ] Assessments directly measure stated objectives (constructive alignment)
- [ ] Instructional activities prepare students for assessments
- [ ] Content is scaffolded appropriately for learner level
- [ ] Accessibility is built in from the start (not retrofitted)
- [ ] Stakeholders have reviewed and provided input
- [ ] Cognitive load is manageable (chunking, pacing)
- [ ] Multiple modalities are represented
