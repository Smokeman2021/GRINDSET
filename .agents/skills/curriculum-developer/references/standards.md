# Standards & Reference

Key standards and frameworks for curriculum development:

- **Bloom's Taxonomy** — Cognitive learning objectives framework (Remember, Understand, Apply, Analyze, Evaluate, Create)
- **Universal Design for Learning (UDL)** — CAST guidelines for inclusive instructional design
- **WCAG 2.1** — Web Content Accessibility Guidelines for digital content
- **Understanding by Design (UbD)** — Wiggins & McTighe backward design framework
- **ADDIE Model** — Analysis, Design, Development, Implementation, Evaluation
- **QTI (Question & Test Interoperability)** — IMS standard for assessment content
- **SCORM / xAPI** — E-learning content standards for LMS compatibility
- **Common Core State Standards** — K-12 academic standards (US)
- **ISTE Standards** — Technology integration in education
