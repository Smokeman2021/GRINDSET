# Curriculum Developer Skill Overview

This skill equips an AI system with five core competencies:

**1. Learning Objective Design**
The system can "Write measurable, student-centered learning objectives using Bloom's taxonomy" and relevant action verbs.

**2. Curriculum Architecture**
It applies backward design methodology to construct coherent programs with both vertical and horizontal alignment across courses.

**3. Instructional Strategy**
The AI selects teaching approaches tailored to specific learning goals and student populations.

**4. Assessment Design**
It develops both formative and summative evaluations that correspond to stated objectives, including authentic assessment methods.

**5. Accessibility Integration**
The system implements Universal Design for Learning principles and ensures "WCAG 2.1 compliance" for inclusive instruction.

This skill transforms AI into a capable partner for educational program development across multiple design dimensions.
