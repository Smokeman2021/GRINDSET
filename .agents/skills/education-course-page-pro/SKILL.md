# Education Course Page PRO

## Core Approach

The workflow prioritizes user definition, minimal structure mapping, and clear hierarchy before addressing responsive design and state management. As outlined, designers should "Define the primary user, task, and success action" first, then establish what information users need to understand in sequence.

## Key Design Principles

The skill enforces several non-negotiable rules: maintain visual dominance for primary actions, keep navigation secondary, and avoid hiding critical details behind interactive-only states. Typography and spacing take precedence over decorative containers.

The guidance emphasizes intentional component variants—default, hover, active, focus, disabled, loading, error, and empty states—paired with explicit accessibility and responsive validation.

## Critical Failures to Avoid

The skill explicitly rejects ambiguous primary actions, important information positioned below the fold, dense layouts lacking scan order, competing visuals, and unaddressed mobile behavior.

## Validation Checklist

Before delivery, designers must confirm users grasp page purpose within five seconds, identify the next action without extensive reading, and account for edge cases and responsive transitions across devices.
