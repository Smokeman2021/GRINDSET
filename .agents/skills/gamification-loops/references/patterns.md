# Gamification Loops: Patterns

## Key Patterns

**Core Loop Design** establishes the fundamental cycle: "Trigger → Action → Reward → Investment" creates recurring engagement. Systems function at different timescales—from session-based (minutes) to long-term progression (months).

**Progress Systems** make advancement visible through various approaches: linear paths feel straightforward but potentially grinding, while S-curve progression mimics natural mastery. The guide emphasizes psychological principles like giving users "endowed progress" by starting at 20% completion rather than zero.

**Reward Systems** distinguish between intrinsic motivation (internally satisfying) and extrinsic rewards (external validation). Variable reward schedules prove more engaging than fixed patterns, matching reward magnitude to effort required.

**Streak Mechanics** leverage loss aversion and identity reinforcement to build habits. Ethical implementations include freeze options and weekend flexibility rather than harsh penalties.

## Critical Anti-Patterns

Designers should avoid dark patterns that manipulate users, overjustification that replaces intrinsic enjoyment with external rewards, and leaderboards that discourage the majority by rewarding only top performers.

The overarching principle: ask whether users genuinely benefit beyond the reward system itself.
