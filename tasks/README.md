# tasks/ — канал задач: Claude (адвайзер у чаті) → Claude Code

Сюди Claude-адвайзер кладе задачі для Claude Code. Більше нічого в репозиторії адвайзер не редагує.

Як працюємо:
- Задачі — файли з номером: `001-...`, `002-...`. Беруться по порядку, якщо не вказано інше.
- На кожну задачу Claude Code кладе звіт у `report/` з тим самим номером (`report/001-...`): що зроблено (файли/рядки), що лишилось, відкриті питання для власника/адвайзера.
- Власник просто каже адвайзеру «переглянь report/» або Claude Code «візьми задачу з tasks/».

Правила для Claude Code:
- Не ламай вхід (invite-login) і RLS.
- Дизайнерські блоки роби ітеративно: спершу 1-2 концепти на апрув, не фіналь наосліп.
- Після задачі онови docs/DECISIONS.md і постав звіт у report/.
